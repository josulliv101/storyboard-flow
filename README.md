 
# Storyboard Flow

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key.
3. Configure Firebase for saved timelines and media uploads. See [apps/web/.env.example](apps/web/.env.example) for the required Admin SDK and Storage bucket variables.
4. Run the app:
   `npm run dev`
